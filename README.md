Importante:  instalar los componentes necesarios y agregar tu llave de acceso para la Inteligencia Artificial. Abre tu terminal o consola de comandos dentro de esta carpeta y sigue estos pasos:

1. Ejecuta el siguiente comando para instalar las librerías necesarias:
   pip install openai pillow requests python-dotenv

2. Crea un archivo nuevo en esta misma carpeta y llámalo exactamente .env

   GROQ_API_KEY=tu_clave_api_aqui
